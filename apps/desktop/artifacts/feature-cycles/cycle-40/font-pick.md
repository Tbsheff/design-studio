# Cycle 40, pick 2: font-pick

## Result

- Added the action `font.list` (`GET /api/projects/:projectId/d/:directionId/fonts`, `scope: "project"`, `access: "read"`, agent set `core`). It returns `pageOf(FontSchema)`: `family`, `source`, `token`, `className`, `stack`, `preview`.
- Added `FontStore` (read service) in `design-system/font-list/`. It calls `harvestNextFonts` (not changed), reads `@font-face`, Google Fonts links and `--font-*` tokens from the CSS and HTML files, and reads the pack fonts and the token entries. The pure engine is `font-list/engine/to-font-rows.ts`. The cache key is the path, mtime and size of each scanned file (P5). Max 200 rows.
- Changed the inspector Font field. A click or Down opens a `.ui-menu` popup with 2 groups: "In this project" and "System". Typing filters the list. Up and Down move the active row and preview it on the canvas. Enter or a click commits 1 version. Escape reverts. A typed family that is not in the list still commits as before; its `data-tip` starts with "This font is not loaded on this page."

## Differences from the spec

- Named the tool `list_font`, not `list_fonts`. `studio/derived-tool-name` fails on a name that is not derived.
- Added the output field `preview`, which holds the resolved token value. With `@theme inline`, Tailwind 4 does not emit `--font-mono` on `:root`, so a `var(--font-mono)` preview did not render. The commit still writes `stack` (`var(--font-mono)`), and the Tailwind map turns it into `font-mono`.
- Changed what blur does. Blur after an arrow-key preview reverts. Blur after typed text commits, as before.
- Stamped `pnpm run new:domain font` before `new:action`, because the stamp refuses a missing domain. The stamp output says "merge step only".
