### UI path

| Pass line | Result | Evidence |

Steps:
1. The agent called `edit_element` on `#card-a-body` 5 times, 400 ms apart (5 to 95 ms each, all succeeded).
2. At the same time the person selected `#card-b-title` in the frame, double-clicked it, typed, pressed Enter, and clicked "Save version".
3. The agent edits all landed on disk. The person's edit was lost in 3 of 4 runs:
   - 2 runs: the frame reloaded after an agent edit between the select and the double-click, so text edit mode never started (focus empty). The typed keys went to the canvas.
   - 1 run: text edit started and the text was typed, but Enter sent no `direct-edit` request. The frame reload ended the edit session and dropped the text.
   - 1 run: both edits survived.
   - With no agent edits, the same steps saved the person's edit every time (`c-17-hand-solo-dark.png`).
4. `set_file_lock` with `["index.html"]` succeeded (3 to 17 ms).
5. `update_file_workspace` and `write_file` failed with the lock message. The result is `isError: true` with only the text. There is no `Forbidden` tag or code in the MCP result.
6. `edit_element` on `#card-a-title` in the locked file succeeded and wrote the text to disk (version `330b2d12…`). The lock does not stop it.
7. The person's hand edit on the locked file worked, as the lock text says it should (`c-17-locked-*.png`).
8. `list_versions` returns `name`, `kind` and `changedFiles`, with no author. Only `write_file` writes "Edit by Claude Code".

Friction:
- F17-1. `edit_element` ignores the file lock. The `set_file_lock` text says "Claude cannot change a file that matches a lock glob, by any tool". High.
- F17-2. An agent edit reloads the frame and ends the person's text edit. The typed text is lost, with no message. High.
- F17-3. No author in Versions or in `list_versions`. Medium.
- F17-4. The lock error has no `Forbidden` tag or code over MCP. A client can only match the text. Low.
- F17-5. The edit bar shows "Discard" at the top right of the canvas. One click outside the frame in that area discards the hand edit session with no confirm (seen during script setup). Medium.
- F17-6. Enter in the chat composer does not send. Only the Send button does (seen during journey 18 setup). Low (may be on purpose).
- F17-7. There is no plain `update_file` tool. The journey names it; the tools are `update_file_workspace` (needs `baseHash`) and `write_file`.
