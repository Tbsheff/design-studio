# Studio optimizations: verified and ranked

Ten Codex agents gave 50 ideas (5 each, areas 01–10). I opened each cited path:line on 2026-10-23 and checked the claim against the current code. Results: 37 Verified, 12 Partly, 1 Wrong. I merged 6 ideas into other ideas (44 entries remain), split 10.3 into two rows, and rejected 3 (1 wrong, 2 not worth it). The full table has 42 rows. Idea IDs are `area.number` (for example 02.5 is area 02, idea 5). I did not re-run the Codex benchmarks. Where a gain came from a large synthetic input, I scaled it to typical sizes and say so.

Context that changes the size of some gains:
- The 274 MB `claude` binary is about 60% of the 458 MB packaged `Resources` folder. The size ideas (09.2, 09.4) save only a few percent of the download.
- The UI loads from local disk or localhost. For 06.1, 06.2 and 06.5 the cost is parse time, not download time.
- The server listens before `warmPreview()` runs (`src/server/index.ts:65–66`). Ideas 01.1 and 01.3 do not shorten app start. Static imports (01.2, 01.5) do load before `serve()`, and Electron waits for server ready.
- New: on first connect the UI asks for `after=0` (`src/ui/events.ts:30,50`). `bus.since()` then reads the whole project event file from disk and replays it (`src/server/store/events.ts:77–80`). In one real project that is 299 KB and 964 events, and 710 of them (74%) are `run.text.delta`. Two connections do this two times. This makes 07.2 and 02.5 stronger than the Codex files say.

## Rejected

- **01.4 Prebuilt bridge for standalone start (Wrong).** No standalone build exists; standalone runs `tsx src/server/index.ts`. Packaged Electron already loads `bridge.js`. The 18 ms esbuild call runs in the background after listen, in dev only.
- **08.4 One-pass alias cycle check (not worth it).** Code is O(n²) only on long alias chains. Real token sets have shallow aliases, so the gain is well under 1 ms.
- **08.5 Reuse compiled tokens in one update (not worth it).** The claim is true (4 compiles, `requireDesignSystem` also compiles), but each compile is a few ms on a small file. The change adds stale-result risk for little gain.
- **(Merged, not rejected)** 10.1 into 02.1; 09.3 into 03.1; 07.1 into 06.3; 07.5 into 06.4; 07.4 into 02.5; 05.2 into 04.4.
