Verify webhook signatures

Tern signs every webhook it sends. Check the signature before you trust the payload, so nobody can fake a “parcel delivered” event on your endpoint.

Reading time 6 minAPI version 2026-09-01Updated 14 Oct 2026

How signing works

Each request carries a Tern-Signature header. It holds a Unix timestamp and an HMAC-SHA256 digest of the timestamp and the raw request body, made with your endpoint’s signing secret.

Example header
Tern-Signature: t=1792915200,v1=5f2b9c1e0a7d4e8f3b6c2a91d0e7f4b8c3a6d9e2f1b0c7a4e5d8f3b6c9a2e1d0

Find your signing secret

  1. Open Dashboard → Developers → Webhooks.
  2. Select the endpoint, then choose Reveal secret.
  3. Store it as an environment variable, for example TERN_WEBHOOK_SECRET.

Each endpoint has its own secret.Test mode and live mode endpoints never share a secret, even when they point to the same URL.

Verify the signature

Use the SDK helper if you can. It checks the digest in constant time and rejects old timestamps for you.

With the Node SDK

  • Node
  • Python
  • Go
import express from 'express';
import { Tern } from '@tern/node';

const tern = new Tern(process.env.TERN_API_KEY);
const app = express();

app.post('/webhooks/tern', express.raw({ type: 'application/json' }), (req, res) => {
  try {
    const event = tern.webhooks.verify(
      req.body,
      req.header('Tern-Signature'),
      process.env.TERN_WEBHOOK_SECRET,
    );
    if (event.type === 'parcel.delivered') markDelivered(event.data.parcel_id);
    res.sendStatus(200);
  } catch {
    res.sendStatus(400);
  }
});

Use the raw body.If a JSON parser runs before verification, key order and spacing change and every signature fails. Mount express.raw() on this route only.

By hand

If there is no SDK for your stack, build the signed string and compare digests yourself:

Python
import hmac, hashlib, time

def verify(body: bytes, header: str, secret: str, tolerance: int = 300) -> bool:
    parts = dict(p.split("=", 1) for p in header.split(","))
    if abs(time.time() - int(parts["t"])) > tolerance:
        return False
    signed = parts["t"].encode() + b"." + body
    expected = hmac.new(secret.encode(), signed, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, parts["v1"])

Common errors

SymptomCauseFix
Every event failsBody parsed as JSON firstVerify the raw bytes
Fails only in productionTest-mode secret in useCopy the live endpoint secret
Fails after a deploy pauseTimestamp older than 5 minSync the server clock with NTP

Rotate a secret

Choose Roll secret on the endpoint. For 24 hours Tern signs with both the old and new secret and sends two v1 values, so you can deploy the new one without dropping events.
